LensS Question Routing

How every question in the Assistant is sent to the right place: the LensS guide, a Genie Quick answer or a Genie Deep analysis. Pick a real example below. The steps it passes through light up and show what happened at each one.

LensS guide (questions about the app) Genie Quick answer (~20–30 s) Genie Deep analysis (1–3 min) Safety rule or escalation

The routing path

1

You ask

Typed in the Assistant, or clicked: a suggested question, an Ask LensS button, a follow-up chip, Go deeper, Answer from the data instead.

2

Clicked or typed?

A click already says where it goes, so it skips steps 3–5. Only typed questions are routed.

no model · instant
3

Signals

Plain word checks on your message and the chat so far: is it a repeat of an earlier question? Does it ask for more ("not enough", "go deeper")? Is it pushback ("you do it")? Does it name the app (tab, filter, export)?

no model · instant
4

Router model

Llama 3.3 70B reads your message and the last three turns (who answered each, and the latest answer's text). It returns where to send it, how deep, what kind of message it is, how sure it is, and the question rewritten to stand on its own.

1 model call · about 1 s · if it fails, the word rules decide
5

Safety rules

Fixed rules over the model's decision so a chat can't get stuck: asking for more or asking again gets a fresh deep analysis; pushback never gets the guide twice; the guide is used only when the model is sure; your Quick or Deep setting is kept unless you ask for more.

no model · instant

How Genie remembers

Genie only remembers its own conversation. Each chat in the sidebar holds two of them, one per mode, and they never see each other.

Quick conversationEvery Quick answer Genie gives in this chat. Follow-ups in Quick go here.
Deep conversationEvery Deep analysis Genie gives in this chat. Follow-ups in Deep go here.

Genie has the history when…

  • it's a follow-up in the same chat and the same mode
  • you reopen an old chat and keep asking in the same mode
  • you click a suggested question inside an existing chat

Genie starts fresh when…

  • you start a new chat, including every Ask LensS button
  • a chat uses Quick or Deep for the first time, such as the first escalation to Deep
  • a "service busy" retry runs (the chat switches to the new conversation)
  • the first question in a mode failed

Genie never sees answers from the cache, guide answers or blocked questions. Step 6 fills that gap by sending the chat so far and the rewrite.
